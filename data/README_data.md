# Data

The datasets used in this study were obtained from publicly available external sources.

## Dataset 1

Statewide California earthquake and stress catalog by Cheng et al. (2026).

- **Source:** https://data.mendeley.com/datasets/2np9vw5v7w/1
- **Required files:**
  - `focmec_ca_final.pickle`
  - `stress_CA_2D_N35_5km_mu_06.pickle`
- **Destination:** Save these files to `data/california/raw/dataset1/`

## Dataset 2

### Earthquake catalog
Refined earthquake focal mechanism catalog for Southern California (1981–2025) by Yang, Hauksson, and Shearer (2012).

- **Source:** https://scedc.caltech.edu/data/alt-2011-yang-hauksson-shearer.html
- **Required file:** `1981-2010_Focal_Mechanism_Catalog.hash`
- **Destination:** Save this file to `data/california/raw/dataset2/`

### Stress catalog
YHSM-2013 from the SCEC Community Stress Model.

- **Required file:** `YHSM-2013.csv`
- **Destination:** Save this file to `data/california/raw/dataset2/`
