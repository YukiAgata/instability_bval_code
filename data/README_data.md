# Data

The datasets used in this study are obtained from publicly available external sources.

## Dataset 1

Statewide California earthquake and stress catalog by Cheng et al.(2026).

Source:
https://data.mendeley.com/datasets/2np9vw5v7w/1

The required files are:

- `focmec_ca_final.pickle`
- `stress_CA_2D_N35_5km_mu_06.pickle`

Place these files in:

`data/california/raw/dataset1/`
