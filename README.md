# Code for "Cascade-up Rupture Growth Model Controlled by Fault-Plane Instability"

This repository contains the code for the analysis presented in "Cascade-up Rupture Growth Model Controlled by Fault-Plane Instability"

## Repository structure

- `analysis/`: Jupyter notebooks and analysis scripts. You use the files here in the analysis.
- `src/`: Python source code.
- `data/`: Data used in the analysis.
- `figures/`: Figures generated by the analysis.

## Analysis workflow
### Analysis of the Synthetic Catalogs
1. `analysis/01_synthetic_catalog_creation.ipynb`
    - Creation of the synthetic earthquake and stress catalog.

2. `analysis/02_catalog_analysis.py`
    - Analysis of the catalogs. Run
    ```
    cd analysis
    python 02_catalog_analysis.py
    ``` 
    - Analysis of the catalogs. As the default setting, real catalogs are also analyzed at the same time.
    - Maximum likelihood estimation of parameters ($\mu, b_{max}, b_{min}, \Delta I$) is conducted at the same time.
    - The results of parameter estimations are stored in `data/analysis_results.csv`.
    - The output figures are stored in corresponding folders in `figures/result`. All figures of Fig.8, some of Fig.10 (related to the synthetic catalogs), and Fig S1 are included in this output.
    - Table 1 and a part of Table 3 in the paper (related to the synthetic catalogs) are created by refering these outputs.

### Analysis of the Real Catalogs
1. `data/README_data.md`
    - Downlowd the necessary data following the description of `data/README_data.md`.

2. `analysis/00_california_data_preparation.ipynb`
    - Create dataflames from the downloaded data. The output files are:
        - 4 csv files in `data/processed/`
        - 13 figures in `figures/dataset/`
      All figures of Fig.6, Fig.7, and some of Fig.11 (a, b, and e) are included in this output.
    - Magnitude of completeness (Mc) is necessary to create datasets but is estimated in this file as well.
    - Datasets with consideration of geothermal fields (GTF) are also created. You can change its radius by correcting the variable `r_km`.

3. `analysis/02_catalog_analysis.py`
    - Run
    ```
    cd analysis
    python 02_catalog_analysis.py
    ```
    - Analysis of the catalogs. As the default setting, synthetic catalogs are also analyzed at the same time.
    - Maximum likelihood estimation of parameters ($\mu, b_{max}, b_{min}, \Delta I$) is conducted at the same time.
    - The results of parameter estimations are stored in `data/analysis_results.csv`.
    - The output figures are stored in corresponding folders in `figures/result`. All figures of Fig.8 and some of Fig.10 (related to the real catalogs) and some of Fig.11 (c and d) are included in this output.
    - Table 2 and a part of Table 3 in the paper (related to the real catalogs) are created by refering these outputs.

### Estimation of minimum magnitude M0
1. `analysis/03_M0estimation.py`
    - Run
    ```
    cd analysis
    python 03_M0estimation.py
    ```
    - Estimation of the minimum earthquake size M0.
    - This estimation is conducted only for `no_error_exp` and `no_error_linear` because other datasets include instability values that are impossible to adress with our likelihood function.
    - The output files are stored in `figures/M0estimation/result`. The figures themselves are not included in the paper but indicate the analysis results.

5. `analysis/03s_M0estimation_plot.ipynb`
    - Visualization of the M0 estimation results.
    - The output files are stored in `figures/M0estimation`. This includes most of Fig.9 (except for Fig.9c).
